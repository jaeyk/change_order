# Other mechanisms (reference)

These models study ways vendor incentives and public costs can diverge other than through amendments. They come from earlier work and are kept unchanged apart from headings and links. The current focus of this folder is [amendments](../amendments/).

| File | Model | Question |
| --- | --- | --- |
| [model3_metered_workflows.md](model3_metered_workflows.md) | 3 | Does paying per action (checks, retries, tool calls) create too much or too little work? |
| [model4_rewarded_flags.md](model4_rewarded_flags.md) | 4 | Does paying per flagged case move the vendor's flagging threshold away from the public one? |
| [model5_shared_validation.md](model5_shared_validation.md) | 5 | Is common testing underprovided when agencies share a cooperative contract? |
| [model6_human_review.md](model6_human_review.md) | 6 | Does the agency's own correction labor weaken vendor effort? |
| [model6_noisy_review.md](model6_noisy_review.md) | 6 (extension) | The same game with a noisy quality signal and an option to commit to a review policy |
| [model7_post_award_substitution.md](model7_post_award_substitution.md) | 7 | When does a vendor swap in a cheaper configuration after acceptance? |
| [model9_metered_and_review.md](model9_metered_and_review.md) | 9 | Models 3 + 6: metered work and agency review together |
| [research_agenda.md](research_agenda.md) | — | The earlier project's simulation and research agenda across Models 1–9 |
| [tool_interactions.md](tool_interactions.md) | — | Which governance tools work as a package, a menu, or substitutes |

Two of these connect closely to amendments:
- **Model 5** is about cooperative purchasing, which the empirical side now measures (horizontal vs. vertical, Figures 1–2).
- **Model 7** is about changes after acceptance; its credibility parameter \(\rho\) depends on the lock-in that Models 1 and 10 study.
